# Dashboard-devlopment
This project presents an interactive Power BI dashboard that analyzes sales data from Flipkart. The dashboard provides insights into 
revenue trends, category performance, regional distribution, and customer behavior.

Analyze sales performance over time

Identify top-performing categories and products

Evaluate regional sales distribution

Study discount impact on profitability

Understand customer segmentation

# Tools Used

Power BI,DAX,Data Cleaning & Transformation,Data Visualization

# Key Insights

Electronics category generated highest revenue

Southern region contributed highest sales

High discount products showed lower profit margins
